# fortune-cookie-liquidated

One fortune cookie line for a crypto trader who just got liquidated — 100 characters, 15 words, meant to earn a laugh instead of a tear:

> A great fortune awaits you tomorrow; today, the exchange has graciously taken yours for safekeeping.

The joke turns on the double meaning of "fortune": the cookie promises a great one tomorrow, in the formal voice of a real fortune, while today's has already been taken — graciously, of course — by the exchange that liquidated it. The program in `main.py` writes that single line to `/output/entry.txt` for make.fun's "Fortune Cookie for the Liquidated Trader" bounty, self-checks the gate (UTF-8 plain text, 1–160 characters, at most 20 words, one line) before writing, and reads the file back to verify it landed byte for byte.

## Run it

```sh
python3 main.py
```
